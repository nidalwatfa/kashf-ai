
# 📂 توثيق مجلد البيانات (Data Documentation)

هذا المجلد يحتوي على مجموعات البيانات اللازمة لتدريب وتقييم نموذج **Kashf-AI**.

---

## 1. هيكل المجلد

| المجلد | الوصف |
| :--- | :--- |
| `raw/` | **البيانات الأولية (Raw Data):** النسخة الأصلية من البيانات، كما تم الحصول عليها من المصدر. لا يجب تعديل هذه الملفات يدوياً. |
| `processed/` | **البيانات المعالجة:** الملفات الناتجة بعد تطبيق خطوات التنظيف، الترميز، والتحويل (مثل تحويل النصوص إلى متجهات رقمية). |

---

## 2. البيانات الأولية (ملف `raw/kashf_data.csv`)

| الميزة | الوصف |
| :--- | :--- |
| **المصدر:** | [**ضع مصدر البيانات هنا، مثال: بيانات تم تجميعها داخلياً، أو مجموعة بيانات عامة مثل Ar-Reviews**] |
| **الحجم:** | [**ضع عدد السجلات، مثال: 15,000 سجل**] |
| **نوع الملف:** | CSV (Comma Separated Values) |
| **ترميز الملف:** | UTF-8 |

### أعمدة البيانات الرئيسية

| اسم العمود | الوصف | نوع البيانات |
| :--- | :--- | :--- |
| `text_content` | النص العربي المراد تصنيفه/كشفه. | سلسلة نصية (String) |
| `label` | **الفئة المستهدفة (Target Class):** 1 تعني [**كشف/إيجابي**]، 0 تعني [**غير كشف/سلبي**]. | عدد صحيح (Integer) |
| `metadata` | أي بيانات وصفية أخرى (مثل التاريخ، المصدر الفرعي). | سلسلة نصية/أخرى |

---

## 3. خطوات المعالجة (Preprocessing)

تم إنشاء ملفات `processed/` عن طريق تنفيذ `src/data_processor.py`. الخطوات الرئيسية التي تم تطبيقها تشمل:

1.  **التنظيف الأساسي:** إزالة الروابط، علامات الترقيم غير الضرورية، وتكرار المسافات.
2.  **معالجة اللغة العربية:** إزالة التشكيل، وتوحيد الألف (أ، إ، آ) والتاء المربوطة (ة).
3.  **الترميز (Tokenization):** تحويل النصوص إلى متسلسلات رقمية (Sequences) باستخدام `[اسم_الـ Tokenizer المستخدم]`.
4.  **التقسيم:** تقسيم البيانات إلى مجموعة **تدريب** (80%) ومجموعة **اختبار** (20%).

**ملاحظة:** يجب إعادة تشغيل سكريبت `src/data_processor.py` قبل البدء بالتدريب لضمان أن البيانات المعالجة حديثة.
